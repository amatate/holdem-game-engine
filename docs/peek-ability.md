# 能力实验：偷看、读牌、换牌

本文件说明当前源码；旧的完整能力规格和里程碑计划属于设计参考，不代表其中的 CLI、持久回放或成长系统已交付。

## 规则

- 网页开桌时选择 classic / ability-lab，默认经典，整场固定。人数 2–6，系统自动安排 NPC。
- 偷看一张：选择一个未弃牌、未淘汰、未公开亮牌的其他对手，随机获知其一张底牌。
- 粗略读牌：同样选择一个对手，只返回“弱／中等／强”。标注读取时的下注轮，后续发牌不自动更新。
- 更换底牌：选择自己的第一张或第二张底牌，以牌堆中下一张未发出的牌替换。无预览、无撤销；旧牌进入本手能力弃牌区，发牌游标推进一张，后续烧牌和公共牌自然顺延。摊牌与输赢按新牌计算。
- 每种能力每场锦标赛最多成功一次；同一个行动机会最多成功使用一种。使用后仍需正常打牌，没有筹码费用。
- 成功使用能力后，即使选择弃牌或提交了非法下注，次数也不退回。只有成功的正常打牌才解除本次能力锁。
- 失败、旧请求和重复点击不扣次数、不改变状态。新的一手清除情报但不恢复次数，重新开桌才恢复。
- 全下但仍未公开亮牌的对手可以被偷看或读牌。NPC 没有能力，不会感知或反制。

## 读牌含义

使用目标的真实两张底牌、当前公共牌和仍在争池的人数，以独立随机分支进行 1000 次模拟。其余玩家的牌按未知牌采样，不读取真实对手牌、烧牌、牌堆顺序或未来公共牌。

令公平份额为 1 / 仍在争池人数：

- 弱：估算底池权益小于公平份额的 0.8 倍。
- 中等：达到 0.8 倍但不到 1.5 倍。
- 强：达到 1.5 倍。

这是相对于随机对手的粗略牌力，不是面对本桌真实底牌、下注范围或边池的精确获胜概率。只给档位，不给目标真实底牌、原始权益、模拟样本或随机种子。

## 状态与信息边界

能力次数、行动锁和本手情报保存在 GameSession 内部，普通句柄不能读取权威状态。网页只收到自己的手牌、公共信息和已授权的私有情报。偷看不把对手座位翻开，读牌不会输出真实底牌，换牌不进入公共日志。正常公开摊牌只展示最终手牌。

偷看／读牌不修改核心状态、发牌或 NPC 随机路径。换牌通过 HoleCardReplaced 核心事件真实更新牌堆账本；事件对公共投影、NPC 和旁观者静默。三者均不增加 NPC 的扑克决策计数，也不替玩家下注。

构造并验证候选状态、能力次数、情报和完整包后，才原子提交。构造失败会丢弃待提交事务，不留下半次换牌或扣次。能力成功后 packet 索引更新，旧请求被拒绝。

刷新和连接恢复读取已提交状态，不重发能力或下注。打牌动画期间不显示最终私有面板，轮到玩家时恢复本手情报；结算清除。网页重新选桌使用页面内确认框，不同端口使用独立 Cookie。

## 五分钟试玩

1. 在项目目录运行 `npm run web`；若要使用 4175，运行 `HOLDEM_PORT=4175 npm run web`。
2. 选“能力实验 · 三种能力”，建议先开 2 人桌。
3. 轮到你时偷看对手：只出现一张情报牌，对手仍是牌背，其他能力暂时锁定；正常跟注／过牌继续。
4. 下一次行动使用读牌：只有档位和读取轮次，仍需正常打牌。下一轮检查读牌结果没有自动更新。
5. 再下一次行动选择换掉自己的某一张牌：主角手牌更新，私有区出现旧牌→新牌，筹码和底池不因能力变化。
6. 刷新：三种次数和本手情报不应重置。完成本手：结算使用最终手牌，私有情报清除。
7. 下一手三个次数仍为 0。重新开“经典德州”：没有能力操作，原有规则和可调速动画继续可用。

## 验证范围与未实现项

自动检查覆盖四轮换牌、牌堆消费与弃牌区、逐事件不变量、最终结算、2–6 人会话三能力组合、非法目标与索引、重复请求、同决策锁、错误回滚、跨手清除、私有 UI 和网络恢复。自动检查不能证明玩法有趣。

尚无持久存档、能力 Session 回放导出、CLI 能力入口、NPC 能力、怀疑值、能力升级或肉鸽成长。经典 replay 显式拒绝换牌事件，避免把能力局误当经典局。重启本地服务会丢失内存中的牌局。
