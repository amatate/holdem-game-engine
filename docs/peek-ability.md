# 能力实验第一版：偷看一张

## 本轮交付

- 网页选择 classic / ability-lab，默认经典，一场比赛不能中途切换。
- 玩家行动时，偷看一个未弃牌、未淘汰、未亮牌的其他对手的一张随机底牌。
- 全下但尚未亮牌且仍有底池资格的对手可以被选中。
- 每场只有一次成功使用机会；失败不扣次数，下一手不恢复。
- 成功后仍停在同一个扑克决策点，必须另行打牌；没有筹码费用。
- 本手私有情报随决策包恢复，本手结束即清除。不存在 NPC 感知或反制。
- 不实现读牌、换牌、怀疑值、存档、能力升级和 CLI 能力入口。旧的三能力完整规格是后续设计，不代表已实现。
- 重新选桌使用页面内确认框，不再依赖内嵌浏览器的原生 confirm 弹窗；不同本地端口使用独立会话 Cookie。

## 状态与信息边界

核心德州状态、公共事件和 NPC observation 不添加能力信息。能力次数与情报只保存在 GameSession 内部；网页只收到已授权的一张牌。对手座位依旧显示牌背，直到真正的公开亮牌事件。

偷看使用独立可复现的随机分支。只增加会话命令与 packet 索引，不增加 core version、不改变 decisionKey、不推进扑克或 NPC 随机路径。下一条扑克命令必须使用更新后的 packet 索引；旧请求会被拒绝。

先构建完整私有包再一次提交，构建失败不扣次数。重复点击、跨标签旧请求和丢失响应不能再次消耗能力。恢复时读取已提交包，不自动重发命令。

情报不进入 public event 动画；后续打牌动画期间暂时隐藏能力面板，回到玩家决策时恢复本手情报，结算时清除。刷新跳过动画并读取真实当前状态。

## 五分钟试玩

1. `npm run web`，网页选“能力实验 · 偷看一次”，建议先开 2 人桌。
2. 等到轮到你，记下筹码和底池，点击“偷看 林岚”。
3. 确认只出现一张情报牌、对手座位仍有两张牌背、剩余次数为 0，筹码不变且仍可正常行动。
4. 刷新：同一张情报仍在，次数仍为 0。跟注／过牌继续，观察情报是否改变你的选择。
5. 本手结束后，确认情报区清除；下一手仍然没有使用次数。
6. 重新开“经典德州”，确认没有能力面板，正常牌局和动画可用。

自动检查覆盖独立随机性、扑克状态等价、非法目标、重复请求、异常原子性、跨手清除、网络恢复和 UI 隔离；是否有趣仍由实际试玩判断。
