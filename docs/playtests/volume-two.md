# 第二卷《散桌以后》与输牌后的选择

日期：2026-11-06。第一卷旧节点和命令语义保留；第二卷是同一行程的第七至十二夜。

## 玩家入口

从第一卷任一已保存结尾点击「带着这些选择，走进第二卷」。中途旧存档继续第一卷，完成后再进入续卷，不需要重开钱包。续卷沿用第一卷已见事实、人物接触和金钱安排。提前离开第一卷也可以进入续篇；此时不会自动获知跳过的剧情。

## 失败处理

默认不强制退回上一章。正式桌负收益和输光时先展示本桌净结果、离桌回收、手头余额，选择「接受损失，继续故事」后保留实际结果并进入后续对白。第二卷每桌都有输/赢/未参加的承接；钱包不足可以买入以外的路径继续。没有必须赢牌的门槛，没有自动借款。

如果想重试，展开「想重新打这一桌？」并确认，撤销仅当前桌的买入与回收、删除仅当前桌结果，回到入桌选择之前。重试不改种子；同样的初始发牌不保证相同打法的不同结局。此前剧情选择、已知材料和其他桌的资金保留。练习桌只撤销记分结果，不改变钱包。赢局、未结算、已经接受损失离开该场景、过期命令和重复点击不能倒退。

## 存档约束

延续同一故事行程槽，逐句与完整结算后保存。第七至十二夜可正常存档恢复。仅明确识别的旧版本可尝试恢复，必须通过完整命令回放和整个公开牌桌摘要一致性检查；不跳过校验、不自动覆盖读不了的旧档。

`tests/fixtures/volume-one-release.json` 来自此前已发布构建的真实运行，含开场、六夜结尾和真实练习局负收益；用于保证不是拿新代码重新生成旧摘要再声称兼容。

## 人工试玩路径

1. 第一卷结尾 → 第二卷入口 → 前进数句 → 回主页 → 继续，核对钱包与对白。
2. 练习桌输一手后离桌 → 继续故事 → 展开重试 → 取消确认 → 再确认，检查回入桌选择且记分钱包没有变化。
3. 正式桌亏损/输光 → 接受损失，检查不下注路线仍可继续；另一轮测试重试是否仅撤销本桌收支。
4. 前卷选择离开 → 第二卷不参与旧屋路线；前卷选择留下 → 参与路线；不要求玩家和解或用牌局胜负揭示真相。
5. 第十二夜完成 → 刷新 → 回看卷末，检查不会又出现第一卷的续篇按钮。
