## 浏览器实测

隔离端口 4183，两人能力桌、人物互动开启，使用真实页面按钮：

1. 偷看一次，弃牌结算：你 99、林岚 101，显示“已保存到第 1 手结算”。
2. 停止 Node 服务，原端口重新启动；浏览器刷新后主页出现留席签，保存手数 1、筹码 99、能力实验。
3. 在 390×844 手机视口点击“继续游戏”；停在同一手结算页，无自动下一手、无重复派奖。展开桌边记录，上一手弃牌事实、人物记忆、净输 1 和结算后 99 都保留。
4. 显式点击下一手，能力面板“偷看一张：本场剩余 0 / 1”；页面提示当前手尚未保存。浏览器无 warning/error。
5. 主页默认 1280×720 与手机 390×844 截图；手机 `scrollWidth === innerWidth === 390`。修正了留席签的窄屏断行；测试后重置视口。
6. 原 4180 页面同步后确认在主页，将原服务切换到新版并刷新，已显示自动保存说明。此端口没有复制测试存档，也没有迁移旧服务内存。

## 明确限制

- 半手进度只在运行中的服务内存，重启回到上次成功结算；旧版已丢失的局无法补存。
- 单浏览器身份／同一主机名和端口、单槽、Cookie 180 天；不是云存档或跨场关系成长。
- 规则／策略／服务端代码指纹不同时拒绝恢复；没有跨版本迁移器。
- 1,000 条操作／2 MiB／30 秒恢复上限。不覆盖断电耐久性、磁盘损坏修复、大规模长期会话压力或真实玩家理解程度。
- 私有种子仅在本机文件；文件不加密，不应公开上传。`.holdem-data/` 已被 Git 忽略。
