# 一屏牌桌体验版

目标：普通桌面 1280×720、窄屏 390×844，在轮到玩家时无需向下寻找公共牌、底牌、底池、跟注金额与合法操作。极矮窗口或文字放大时允许自然滚动，不裁掉内容。

## 视觉与布局

- 夜色 `#101d2b`：页面背景。
- 桌毡 `#145448`：牌桌与观察反馈。
- 黄铜 `#e7bb72`：当前行动与主要按钮。
- 纸白 `#fff9eb`：牌面与正文。
- 灰蓝 `#a6b7c3`：次要信息。
- 深蓝 `#182a3b`：桌沿与展开面板。
- 标题沿用宋体；操作与说明用苹方 / 微软雅黑；筹码数字用 Georgia。
- 特征：紧贴牌桌的「桌沿行动条」。不重复创建投注按钮，不缩小可点击区域来硬塞一屏。

```text
夜局 / 模式                      同步
节奏                         速度 / 跳过
人数 / 手数 / 街道                  盲注
           对手与公开气泡
         底池 / 五张公共牌
            你的底牌与筹码
────────────────────────────────────
轮到你 · 待跟金额       可争夺金额
弃牌 / 跟注 / 全下       加注到 [ ]
暗手（能力模式） / 桌边记录 / 教学详解
```

自检：单纯缩短桌高会造成座位与公共牌重叠，因此一并调整座位比例与玩家底牌的横向排布。详细聊天、观察依据和结算账单保留在可展开区域；最新反馈在摘要可见。教学的当次提示不能仅藏在展开面板。展开状态在同一牌桌重绘后保留；换桌清除，不把旧私有情报带入新桌。

## 反馈与边界

- 保留逐事件播放、速度、跳过与减少动态效果设置；只在已发生的事件上展示气泡，不预演后面的结果。
- 每手至多两条动作观察；普通翻牌前动作不抢占名额，至少一个名额留给更重要的交锋。具体规则与测试由 living-table 实现维护。
- 不新增规则、作弊能力、NPC 隐藏信息权限或 LLM。
- 本轮不发布 GitHub；真人试玩表为待执行模板，自动检查不能代替真实受试反馈。

## 验证

- 2 / 4 / 6 人布局、桌面和窄屏；经典、能力、教学入口。
- 操作、输入合法范围、能力回执、结算、播放跳过、展开状态保持。
- 关键隐私与回放回归；原长用例单独低并发复查，不修改限时掩盖失败。
