# 结算点续玩 v1

范围：结算后自动存档、主页继续游戏、最近六手公开交锋回顾。经典、能力、人物互动、序章和教学共用同一边界；不保存半手，不新增能力、剧情或模型。

## 行为与边界

- 本地服务每个浏览器身份一个存档槽，Cookie 持续 180 天；同一浏览器、主机名与端口恢复。不是账号或云存档。
- 只在手牌／比赛结果，以及结果页回答剧情／教学问题后保存。下一手尚未结束时仍保留上次结算。新开桌不会立即删除旧存档，第一手结算后才覆盖。
- 恢复必须显式点击，停在原结算页，不自动下注、发下一手或再次派奖。恢复使用新牌桌 ID，拒绝旧页面指令。
- 用原始种子和已接受命令重建确定性引擎、能力次数、NPC 记忆、剧情与教学状态；校验运行代码指纹和最终状态摘要。私有种子／命令日志只在服务端，不出现在浏览器协议中。
- 文件写入临时文件后原子替换，权限 0600；失败保留上一个结算点，并显示错误。损坏、版本不匹配或重建不一致时不加载、不自动删除。
- 首版上限 1,000 条已接受操作／2 MiB，恢复最多 30 秒；超限保留上次存档并提示。不保证跨规则版本兼容，不做跨场成长。
- 测试服务器默认关闭磁盘存储，只有显式配置或命令行启动才开启。

## UI 设计（实现前审视）

延续夜局的夜蓝 `#101d2b`、墨绿 `#145448`、黄铜 `#e7bb72`、牌纸 `#fff9eb`、灰蓝 `#a6b7c3`、面板蓝 `#182a3b`。标题用 Songti/STSong，正文用 PingFang/Microsoft YaHei，筹码数字用 Georgia。

布局：主页第一块是一张横向“留席签”，牌桌保持一屏操作，状态及回顾放在操作区后方。

```text
主页：[留席签｜第 N 手已结算｜筹码 / 时间｜继续游戏]
      [新手教学] [短序章]
      [自由牌桌与模式设置]

牌桌：[牌桌 + 操作区，原布局]
      [已保存到第 N 手 · 返回主页]
      [暗手] [桌边记录含最近六手] [教学 / 故事]
```

审视：不增加泛用数据仪表盘或大标题，把真实手数与恢复位置作为唯一视觉重点。留席签的分隔线借用纸签票根，按钮明确“继续游戏”，说明明确“回到结算”。在牌桌上不展示保存时间等冗余信息，避免挤占下注区。

## 验收

- 重启真实 HTTP 服务后：所有筹码／能力次数／人物公开记忆与下一手行动一致。
- 中途退出恢复上次结果，拒绝过期指令；结果页回复、教学答案及序章结尾可恢复。
- 存档损坏、版本变化、保存失败、无 Cookie、跨身份、重复恢复不造成隐式重开或重复结算。
- 浏览器主页入口、恢复结果、最近交锋、移动端布局实测；不以接口测试代替页面测试。
