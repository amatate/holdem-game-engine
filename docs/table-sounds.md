# 牌桌音效 v1

## 当前 BGM：轻柔爵士（2026-10-03）

当前本地 BGM 已改为 Kevin MacLeod 的 [Cool Vibes](https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1100863)：83 BPM 的颤音琴、贝斯与鼓三重奏，作者标记 Calming / Relaxed，许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。音乐菜单可见作者、信用文件和许可链接；原 MP3 未改编，218.384 秒、8,737,561 bytes，来源和 SHA-256 保存在 `src/web/audio/MUSIC-CREDITS.txt`。不是无缝循环素材，播放完整曲目后重播。原《Bebop (Chiptune)》仅作为历史试听文件保留，不再提供运行时路由或打包进入 Pages。下方 v1 验证记录描述原短音效版本，不是本次换曲验收。

`src/web/music.ts` 独立管理音乐：默认关、20% 音量，开关/音量仅存浏览器偏好，不进牌局存档。用户手势后播放，后台暂停，返回页面续播；音效静音、动画倍速与跳过不改变 BGM。音乐播放失败、下载失败、快速开关等不会提交任何牌局命令。中英文、Node 和 Pages 同步接入。音乐气质需要耳听验收，不把成功加载等同于风格认可。

## 范围与来源

用公开、许可明确的短音效补足发牌和筹码反馈，不增加 BGM、角色配音或外部音频服务。选用 Kenney 的 Casino Audio 1.1 与 Interface Sounds 1.0；2026-09-28 同时核对了官网标记、[作者许可说明](https://kenney.nl/support)和原包 License.txt，均为 CC0。素材信用与完整映射见 [audio/README.md](../src/web/audio/README.md)。

11 个 WAV 共 414,352 bytes，单声道 44.1 kHz PCM16，每段不足一秒。处理脚本保留源文件哈希、输出哈希、实际峰值和时长；只有转换后的选中素材及信用文件进入 Node / Pages。素材的 CC0 不改变其他代码或美术的许可。

## 行为边界

- 声音系统只接收当前正在展示的公开 PlaybackFrame 及已经展示的成功结果，不能访问未公开底牌或改动游戏状态。
- 发牌／翻牌每事件一声，不按每张牌叠加。人物发言的 reactionOnly 帧不重复声音，不为语言切换或笔记展开播放牌局音效。
- 新的玩家决策有轻提示，能力成功使用后有短反馈。同一 decisionKey 的普通剧情回应不重复回合提示。
- 只有玩家净赢时才在结算后庆祝；边池拿回钱但总体亏损不算获胜。最终冠军也有提示。
- 解锁／下载／解码在声音系统内部异步完成，不让游戏 await。未就绪时直接丢弃当下声音，之后不补播。
- 默认音量 40%，每类声音另有相对增益。同一 cue 间隔至少 100 ms，最多两路短音效；多余旧声音停止。发牌变体用独立顺序计数，不消耗引擎随机数。
- 跳过时停止现有声音，不播放被跳过的帧；最终到达新的玩家决策或净赢结算可以保留一声提示。刷新、同步、读档及网络失败后的同步保持安静。
- 系统“减少动态效果”仍可独立保留音效；声音和视觉动效各自可控。后台不播放、切后台停止当前声；不会保存待补播队列。
- 浏览器以真实 pointerdown / keydown 解锁 AudioContext。静音和音量存在 `holdem.sound.v1`，不进入存档。素材加载超时／失败或 Web Audio 不可用时显示提示，不影响规则与输入。
- 既有版本指纹机制不变，新构建可能不兼容旧存档，仍保留旧存档并说明原因。

## 实现

- `src/web/sound-assets.ts`：唯一的 cue / 文件 / 增益映射和固定服务路径清单。
- `src/web/sound.ts`：事件映射、边界提示、可注入音频 IO、限流／停止／静音及中英文设置。
- `src/web/client.ts`：只在真正的逐帧播放和成功动作完成后触发；跳过／回主页停止，bootstrap / resume 不触发。
- `scripts/import-sounds.mjs`：离线素材转换工具，需要 ffmpeg/ffprobe；游戏运行不需要这些工具。

## 验证

本地类型检查、Node 构建、Pages 构建通过；完整串行回归 **65 个文件 / 863 项测试通过**。新增检查覆盖事件映射、额外反应帧不重复、净赢而非毛派奖、用户解锁、样本加载失败、静音、零音量、后台、最多两路、取消尚在加载的试听、PCM 与哈希、固定路由及 MIME。客户端真实引擎测试验证正常行动发声、同步／读档安静、跳过不挤播。

浏览器独立预览确认：首次点击后样本全部解码且 AudioContext 就绪；试听与静音可操作；刷新保留静音；中英文切换后控件继续工作；键盘将音量从 40 调到 35；390 × 844 英文音效菜单没有横向溢出。浏览器未观察到控制台错误。

这些是加载、解码、事件触发和控件验证，不等于用户已完成耳听验收。建议亲自以 1× / 4× 打一手，按耳机或音箱调音量，再判断是否需要更安静的筹码声或其他提示音。源码／本地预览、GitHub 推送和 Pages 部署是分别核对的状态，不能把本地通过说成已上线。
