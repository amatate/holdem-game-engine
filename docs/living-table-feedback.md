# 活牌桌：普通桌接入与可见反馈

## 本轮范围与实施顺序

1. 将人物互动与规则、剧情拆开。自由桌保持 2–6 人、经典／能力规则；主页默认勾选「人物记忆与闲聊」，取消后使用原参数化 NPC。旧 API 未传选项时保持关闭。剧情入口固定开启，教学不启用。
2. 人物按实际名单与座位建立，不再假设林岚永远坐 1 号、莫叔永远坐 3 号。自由桌不带剧情提示或六手截止。
3. 台词与记忆提示携带公开事件锚点（packetIndex + 本包 eventIndex），只在对应动画事件到达时出现。一次只呈现一位说话者，延时跟随现有倍速、跳过与减少动态效果设置。
4. 牌桌与操作区之间常显「桌边动态」：最新短句、明确的第几手来源、最近一次“记住了你”的事实与谨慎推测；可展开近期记录。观察面板仍保留 NPC 的公开动作统计。聊天收起只隐藏台词，不关闭记忆。
5. 关键回归与浏览器验收：2–6 人的名单一致性、关闭保留旧行为、超过六手、教学／剧情边界、事件对齐不剧透、刷新不重复、能力不泄漏、桌面与窄屏布局。

## 视觉与交互

沿用夜蓝 #101d2b、桌毡绿 #145448、筹码金 #e7bb72、牌纸白 #fff9eb、灰蓝 #a6b7c3。标题宋体、正文系统黑体、数字 Georgia。

标志元素是 NPC 座位旁的牌纸色短句气泡，配合同一说话者的座位描边；不添加震动、闪屏或自动滚屏。下方留一条可回看的桌边动态，不把记忆藏在折叠人物介绍里。小屏气泡放在座位内侧，长文留在动态条，防止遮住牌面与筹码。

布局：牌桌 → 桌边动态（最新一句 + 记忆依据）→ 正常操作／结算 → 独立剧情；右侧为人物观察与本手记录。主页选项紧邻规则与人数，不改变“只选人数、系统安排 NPC”。

## 诚实边界

“记住了你”只表示该 NPC 看到了可核对的公开动作，不承诺它下一次必然针对玩家。策略仍选择公开行动中的相关对手，调整幅度有上限，不是读心或长期学习。记忆最近八手、重开／重启重置；初见也可记录事实，至少三手才形成倾向。表现层另按事件顺序积累公开证据，不能从已经算完的整段 NPC 行动中提前取数。

本轮不加永久存档、在线 LLM、自由聊天、新能力、公开发布或大规模 UI 重做。

## 验收记录（2026-09-08）

- 类型检查、生产构建、完整串行回归：59 文件／778 项通过。覆盖 2–6 人实际名单、人物开关、无剧情自由桌、八手窗口、最少样本、刷新幂等、隐私、事件锚点、旧包不重播、多角色回应不重复付筹码，以及原有规则／能力／教学回归。
- 浏览器普通四人桌：加注到 4 的公开行动触发林岚气泡与记忆提示，同帧尚未显示对手后续弃牌／下注。跳过后保留可回看文本；收起闲聊和刷新后原记忆文本一致。
- 同一普通桌实际继续到第七手，没有序章截止。第六手记录包含近六手主动一手、弃牌五次的公开事实，以及“不是读牌”的谨慎推测。
- 390px 手机视口：页面宽度为 390，跟注事件的林岚气泡不与牌面矩形相交；0.5× 下气泡与完整动态可读。已恢复默认视口。
- 六人能力桌人物为老周、林岚、阿凯、苏蔓、韩烈；偷看后前台人物动态不变，所得牌留在私有能力区。关闭人物选项再开二人经典桌，没有动态区，顶部恢复“经典德州”。
- 新服务在 `http://127.0.0.1:4181/`，未重启已有 4180 牌局。其他端口的旧进程仍是旧后台，体验新功能请用 4181。源码变更尚未推送 GitHub。

自动检查证明流程与信息边界，不证明 NPC 已达到真人水平。气泡是有限模板，单手最多一条记忆提示、两条普通闲聊和一条重大输赢回应；初见对白与剧情回应另计。最近一次记忆／短句常显，其余记录可展开重读。
