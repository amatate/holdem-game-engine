# 浏览器经典牌桌：首段可玩交付

依据：用户在 2026-09-05 评估后说“开始”，批准先交付浏览器经典桌、随后再做一个可选偷看能力。本次只完成第一段，不更改经典规则、NPC 策略或现有 CLI。

## 产品与交互

- 玩家选择 2–6 人；默认 4 人，系统沿用已有固定阵容。
- 开局后立即进入真正的牌桌：自己的底牌、公共牌、各座位筹码、按钮/盲注位置、实际行动、当前桌面投入和合法按钮。
- 加注输入表示“加注到”，范围只取当前 ActionPanel；请求期间锁住操作，拒绝过期/重复命令后重新同步。
- 每手结束停在结算，显示实际最佳五张、牌型、各池赢家、投入/退回/净结果；点击下一手继续。淘汰后可继续观看，比赛结束显示冠军。
- 刷新恢复当前本地会话；关闭服务或闲置两小时后不保留。重新开桌前确认。
- 无账号、联机、云部署、存档、能力按钮占位、虚构心理台词或新增策略。

## 技术边界

- 在既有独立 worktree 继续。TypeScript + 原生浏览器模块 + node:http，不增加依赖或重建工程。
- Node 持有 GameSession；浏览器只收到 TurnPacket、由公开事件派生的牌桌视图以及公开角色资料。随机种子、牌库和未公开对手牌不发送。
- 服务只监听 127.0.0.1，检查 Host/Origin；HttpOnly SameSite=Strict 会话 Cookie；只暴露白名单静态文件；JSON 请求限长，串行处理同一桌命令。
- 请求包含独立 tableId 及 packetIndex/decisionKey，防止旧页面操作新开桌。
- 首次可辨认、可用界面编译完成后立即打开本地预览。完整浏览器视觉/操作体验由用户试玩反馈，不把 HTTP 或单测当成人工验收。

## 视觉方案

牌桌是主画面，不做营销页或管理后台。两种布局比较：矩形数据表易实现但失去空间关系；椭圆牌桌保留对坐关系，选后者，窄屏变纵向牌桌。

- 背景 midnight #101D2B、桌面 felt #145448、桌沿 slate #273B4C、纸牌 paper #FFF9EB、强调 brass #E7BB72、红色 vermilion #CA4B50。
- 中文标题用宋体衬线（Songti SC / serif），正文 PingFang SC / sans-serif，筹码与牌面 Georgia / monospace，主要控制不小于 14px。
- 标志性元素是中央公共牌与沿桌沿分布的角色席位；周边记录收敛成一列。头像用姓名字标，不为首版生成插画。
- 明确键盘焦点、可用禁用态、移动端滚动、减少动态效果偏好；牌型与金额不能只靠颜色区分。

## 验证边界

少量针对新边界的测试：合法操作推进、旧命令不重放、短码与结算展示、2/6 人阵容、刷新恢复、底牌/种子不泄露、本地请求保护。交付前运行现有全套回归、类型检查与构建。能力扩展留给下一段。
