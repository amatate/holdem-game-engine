# 活牌桌 v1 与新手教学

日期：2026-09-08。下述范围已实现，技术与浏览器验收见文末；主观体验仍待用户试玩。

## 体验范围

- 主页提供独立的「新手教学」「活牌桌 · 序章」入口，原经典／能力自由牌桌保持 2–6 人可选。
- 活牌桌固定玩家、林岚、阿凯、莫叔四人，最多六手；玩家淘汰或比赛提前结束也进入结尾，不修改引擎胜负或筹码。可用经典或能力规则，独立标识玩法与体验。
- 三个剧情节点：入座、第三手后、离桌。主角是受邀来访的普通人，通过沉默、示好、直言形成本场表达倾向；不强行设定身份、作弊身世或完整长篇主线。
- NPC 公开行动记忆限定最近八手，至少三手可见行动才形成倾向，三至五手标注样本较少。性格是基础配置，策略调整有上限；本手多次加注会提高警惕，前次主动下注会给后续主动性一个小偏置，并不是完整多轮策略求解。
- 台词按公开事件触发，有每手上限、同类冷却；聊天可收起，不影响下注。NPC 会互相回应。大输赢后的情绪会随手数回落。
- 观察笔记仅列公开行动统计／已公开摊牌结果，推测明确标注，不显示策略内部理由或暗牌；能力情报不进入角色系统。
- 本场人物记忆、剧情选择、教学进度可刷新恢复；重开重置、服务重启丢失。不宣称永久存档或学习型 AI。

## 教学三关

1. 两人练习桌：认识底牌／公共牌、盲注、跟注、过牌、翻牌／转牌／河牌，真实引擎摊牌。对手配合跟注／过牌。
2. 独立练习桌：加注到指定金额，对手再加注，练习弃牌止损；说明本轮总额与本次支付的区别。
3. 独立练习桌：可以自由使用所有合法行动；结算后复习七张选最佳五张、牌型等级与踢脚牌。

每关结算后一道理解题，答错给解释、可重试，不扣筹码；答对才能进入下一关或完成教学。支持重试当前关与返回主页。指导动作是显式教学限制，不修改核心合法行动；错误动作由教学层拒绝，不前进、不消耗牌或筹码。固定种子仅用于教学，对手明确标注为配合练习，不代表正式 NPC 强度。

## 分层与信息边界

规则引擎 → GameSession / TurnPacket → 网页投影
                 ↑                        ↓
          参数化策略 + 公开行动记忆      教学提示 / 人物短句 / 观察笔记

自由牌桌不启用记忆策略，保持旧行为。人物模块只接收公共事件的白名单投影，不接收自己的底牌事件、能力回执或私有策略 trace。教学只是选择固定种子、练习对手、允许的引导动作与课后问题，仍由原引擎结算。

HTTP 更新继续使用 tableId、packetIndex；对话／答题另有 revision 防止重复或过期提交。新关卡使用新 tableId，避免重置 packetIndex 后旧动作误入新关。

## 界面计划与自审

沿用夜局材质：夜蓝 #101d2b、桌毡绿 #145448、筹码金 #e7bb72、牌纸白 #fff9eb、灰蓝 #a6b7c3、暗红 #ca4b50。标题宋体、正文系统黑体、筹码 Georgia；不加载远程字体。

主页先出现一张横向「入桌邀请」：左侧教学入口，右侧人物序章入口；下方仍是已有牌桌预览和自由开桌。教学卡像桌边的规则便笺，紧贴操作区；人物短句像桌边记事，不覆盖牌面或拖长动画。

```text
主页： [先学三小关 →] [与林岚、阿凯、莫叔入座 →]
       [原有牌桌预览 / 人数 / 经典与能力模式]
牌桌： [规则状态与桌面] [人物 / 本场观察 / 本手日志]
       [教学便笺（仅教学）]
       [正常行动或结算]
       [剧情节点与桌边短句（仅序章）]
```

自审：不另做通用营销大标题与统计卡，保留绿毡牌桌作为主视觉；金色只引导当前可操作的入口／提示。390px 不横向溢出，键盘可操作，尊重减少动态效果。对话不读完也能打牌，静音不改策略。

## 验收

- 教学三关端到端：错误动作不推进、课后答题、重试／刷新／退出／自由开桌；结算筹码守恒。
- 相同公开行动产生相同记忆；重复投递不重复记数；样本不足不贴标签，窗口外记录过期。不同暗牌或能力回执不能改变人物观察。
- 记忆策略确实影响有界策略参数，不只有台词变化；策略仍返回合法操作。经典自由桌旧回归不变。
- 六手序章与提前淘汰均可收尾，三名人物台词有差异，选择只提交一次，剧情不左右发牌结算。
- 类型检查、构建、相关测试、完整串行回归；桌面及窄屏人工浏览器验收。
- 自动化只证明规则与流程；「更像真人」「好玩」「新人真正学会」留给用户试玩判断。

## 刻意保留的边界

本轮不做对手范围求解、自由聊天、长期人物记忆、永久教学通关标记或完整剧情。对手记忆统计与个人印象只在本场存在，模板短句有沉默与冷却，不是每次动作都说话。教学对手是配合脚本，不能用其胜率评价正式 NPC。
