# Holdem Game Engine

一个用 TypeScript 编写的德州扑克（No-Limit Texas Hold'em，NLHE）文本游戏 MVP。

v0.1.0 的目标是先把真实德州规则、完整牌局流程和不同风格的角色跑通。当前版本可在终端中进行一场四人锦标赛：你对战三名电脑角色，直到只剩一名冠军。主角能力、作弊机制和肉鸽成长尚未加入。

> 这是 GitHub 源码版本，未发布为 npm 软件包。

## 当前内容

- 52 张标准牌组、洗牌、发底牌和公共牌
- 按钮位、小盲、大盲与各下注轮的正确行动顺序
- 弃牌、过牌、跟注、下注、加注和全下
- 最小加注、短码全下、加注权重开与自动发完公共牌
- 未被跟注筹码退还、主池/边池、平分底池与奇数筹码分配
- 九类牌型比较，并在摊牌时显示牌型与实际最佳五张
- 淘汰、盲注升级和锦标赛结束流程
- 固定种子重放：相同种子配合相同行动可复现牌局
- 只向角色 AI 提供其应当看到的信息，不泄露其他玩家底牌

内置四种角色风格：

- 老周“岩石”：紧、稳健、低风险
- 林岚“猎手”：重视位置，主动施压
- 阿凯“疯狗”：宽松、激进、变化大
- 莫叔“跟注站”：宽松、黏性强、很少主动加注

默认终端牌桌由“你”加上猎手、疯狗和跟注站组成；“岩石”风格已经在引擎中提供，但不在默认四人桌中出场。

## 环境要求

- Node.js 22 或更高版本
- npm

## 安装与运行

克隆仓库并进入项目目录后：

```bash
git clone https://github.com/amatate/holdem-game-engine.git
cd holdem-game-engine
npm install
npm run play -- --seed demo-1
```

`--seed demo-1` 用来固定随机种子，便于复现和讨论同一局牌。也可以不传种子直接开始随机牌局：

```bash
npm run play
```

## 操作方式

终端每次会列出当前真正合法的操作：

| 输入 | 含义 |
| --- | --- |
| `f` | 弃牌 |
| `x` | 过牌 |
| `c` | 跟注 |
| `r 20` | 加注到 20，而不是额外再加 20 |
| `a` | 全下 |

例如提示 `r 4-100 加注到` 时，输入 `r 20` 表示把本轮下注总额加到 20。不能过牌时需要跟注或弃牌；当前版本中，面对“过牌”场景请使用 `x`，不能用 `c` 代替。

自动发生的牌局事件默认每秒输出一行。轮到你行动时，牌桌状态和操作菜单会立即完整显示，不会逐行等待。

## 验证

```bash
npm test
npm run check
npm run build
```

测试包含固定种子的 100 手随机规则回归，覆盖 2–6 人桌、多种初始筹码和盲注组合；这用于检查筹码守恒、合法行动、事件回放和牌局能否正常结束。

## v0.1.0 的范围

当前已经是一套由真实规则驱动的文本游戏，不是预先写好的对话脚本。它仍是第一版规则与交互 MVP，暂不包含：

- 浏览器或图形牌桌
- 联机、多人真人对战和服务器
- 存档、账号与长期局外成长
- 主角特殊能力、作弊牌、道具或肉鸽事件
- 剧情、角色关系和赛后复盘
- 求解器级或 GTO 级 AI
- 自定义终端输出速度
- 行动阶段把“暂时尚未跟齐”的投入与真正边池区分展示
- 按牌型语义重新排列最佳五张的显示顺序

当前角色 AI 主要依靠可见信息、牌力估计和风格参数做决定，目标是形成可辨认的性格差异，而不是模拟职业牌手的最优策略。下一阶段建议见 [docs/next-stage-recommendations.md](docs/next-stage-recommendations.md)。
